# wardlm — Landing Page

Landing page de [wardlm](../wardlm), construida con Next.js 15 y Tailwind CSS.

## Stack

- **Next.js 16** (App Router)
- **Tailwind CSS v4**
- **TypeScript**

## Desarrollo local

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en el browser.

## Deploy

La landing está pensada para desplegarse en Vercel. Apunta el proyecto al directorio `wardlm-landing/` como root.
